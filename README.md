# Quiz Studio

ブラウザで問題を作り、まとめて解く、小さな問題演習アプリです。
アカウント登録、APIキー、アプリケーションサーバーは不要です。問題集と回答は利用者のブラウザに保存します。

**v0.1.0** · [デモを開く](https://hk2513.github.io/quiz-studio/) · [ソースコード・問題報告](https://github.com/hk2513/quiz-studio)

## できること

- 問題集・問題の作成、編集、複製、削除
- 任意のカテゴリ階層、単元、問題ごとのタグ
- 4択を標準に、2〜6択の単一選択・複数選択・記述（完全一致）
- 問題文、正答、解説のプレビュー
- 既存の10列CSV、バージョン付きJSONの読み込みと書き出し
- 既存の `manifest.json` とCSVをフォルダーごと読み込み
- 読み込み前の検査・確認、既存問題集への更新または別コピーとして追加
- 複数のカテゴリ・問題集を組み合わせた出題、タグ・誤答による絞り込み
- 問題数の指定、問題順・選択肢順のシャッフル
- 「回答する」で確定、前後移動、回答一覧、採点、解説、誤答の再演習
- 途中保存・再開、解かずに解説を読むモード
- スマートフォン向けレイアウト、下部固定ナビ、文字サイズ切り替え

## まず使う

[デモを開く](https://hk2513.github.io/quiz-studio/)と、登録なしですぐに使えます。作った問題や回答は、その端末のブラウザ内に保存されます。

手元で使う場合はGitHubのCode → Download ZIPで入手します。ZIPを展開し、`web/index.html` をブラウザで開きます。例題6問が入っています。ビルドやパッケージのインストールはありません。

`file://` の保存可否・保存範囲はブラウザに依存します。安定した保存にはHTTPS上の静的サイト、または次のlocalhostサーバーを使ってください。ブラウザ内の保存に失敗した場合は画面に表示します。サンプル以外の重要な問題集はJSONでも保管してください。

Node.js 22以上がある場合：

```sh
npm run dev
```

表示された `http://127.0.0.1:4173/` を開きます。開発用サーバーは静的ファイルを配信するだけで、問題データを受け取る機能はありません。

Pythonがある場合は、代わりに次でも確認できます。

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory web
```

## 使い方

### 作る・編集する

1. 「問題集を作る」で名前と分類を登録する。
2. 「問題を追加」で問題文と選択肢を入力し、正答にチェックする。
3. 解説を入力する。各選択肢の理由を書くと、復習しやすくなります。
4. 「保存する」。問題集の名前を押すと、あとから編集・複製・削除できます。

カテゴリに `語学 / 英語` と入力すると、階層が分かれます。問題集が1冊だけでもカテゴリは表示されます。タグはカンマ区切りです。問題編集中の入力は「保存する」を押すまで確定しません。保存せずに移動する場合は確認します。

### 解く・読む

問題集の左のチェックを選び、「演習する」から問題数・シャッフルを設定します。複数カテゴリを同時に選べます。選択肢を選んだだけでは採点しません。「回答する」で確定します。

下部の「前へ」「次へ」、上部の「問題一覧」で移動します。未回答を残して結果を見ることもできます。「中断」後は一覧の「再開する」から戻れます。保存する演習は1回分です。過去の最終正誤は別途記録します。

「読む」は採点せず正答・解説を確認します。問題集を編集しても、保存済みの演習は開始時の問題と正答を保ちます。改訂後の問題で解きたいときは、問題集一覧から新しく演習を始めてください。

### 持ち運ぶ

「読み込む」からCSV・JSONを選び、プレビュー後に「取り込む」を押します。新しい問題集は一覧の先頭に追加されます。JSONに同じIDの問題集がある場合は、「別の問題集として追加」または「同じIDの問題集を更新」を選べます。

問題集の「書き出す」からCSV・JSONを保存できます。すべての問題集は「設定 → 問題集をJSONで書き出す」。**JSONは分類・タグ・IDも保持します。CSVは問題文・選択肢・正答・解説の互換形式です。** 学習履歴や中断データは書き出しません。

## 保存とプライバシー

- 保存先は同じ端末・同じブラウザ・同じオリジンのIndexedDBです。サイトデータを消すと問題集・履歴も消えます。
- 別端末への同期、共同編集、公開問題集の検索・配信機能はありません。
- ファイルはブラウザ内で読みます。外部API・解析・フォントCDNは使いません。
- 読み込んだHTMLは制限された文字装飾だけ表示し、スクリプト・画像・リンク等を実行・読み込みません。
- 複数タブの古い状態による上書きは検知して停止します。その場合は当該タブのJSONを書き出してから再読み込みしてください。
- 自動バックアップ・暗号化保管ではありません。共有端末での個人情報や機密情報の保存には向きません。

## 現在の制限

- 画像、音声、動画、数式レンダラー、自由記述の意味判定は未対応です。
- CSV内の画像タグなどは文字データとして残りますが、画像としては表示しません。取り込み時に案内します。
- 大量データの上限は一度の読み込み20MB・1,000ファイル、1問題集10,000問。上限いっぱいでの負荷試験は未実施です。
- オフラインでの再訪を保証するService Workerはありません。ローカル配布物はネット接続なしで利用できますが、保存挙動はブラウザ依存です。
- 対象は現行のChromium・Firefox・Safari。今回の実機検証はChromiumのみ。モバイルは狭いビューポートで確認し、iOS/Android実機は未検証です。
- 学校の採点や資格試験の厳密な管理システムではありません。問題の内容・正答の妥当性は作成者が確認してください。

## 開発

Node.js 22 / 24、標準ライブラリだけでテストできます。

```sh
npm test
npm run check
npm run dev
```

`web/` が配布対象です。`web/js/core.js` はモデル・検証・演習エンジン、`formats.js` はCSV/JSONの互換処理、`storage.js` は永続化、`app.js` は画面と操作、`samples.js` はオリジナル例題です。外部ランタイム依存はありません。
