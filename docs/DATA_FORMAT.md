# データ形式

## JSON v1

`examples/sample-library.json` がそのまま取り込める完全な例です。

```json
{
  "schemaVersion": 1,
  "sets": [{
    "id": "collection-one",
    "title": "計算の練習",
    "category": ["基礎", "算数"],
    "unit": "足し算",
    "description": "短い練習問題",
    "questions": [{
      "id": "question-one",
      "type": "single",
      "prompt": "1 + 1 は？",
      "choices": [{"id":"1","text":"1"},{"id":"2","text":"2"},{"id":"3","text":"3"},{"id":"4","text":"4"}],
      "correct": ["2"],
      "answer": "",
      "explanation": "②が正解。1を2つ合わせると2です。",
      "tags": ["基本"]
    }]
  }]
}
```

IDは英数字・`-`・`_`の1〜100文字。`__proto__`、`constructor`、`toString`などObject.prototypeの組み込み名、および`prototype`は使用できません。問題集ID・問題IDはそれぞれ全体で一意です。正答は表示順ではなく選択肢IDを指定します。

- `single`: 選択肢2〜6個、正答1個。
- `multi`: 選択肢2〜6個、正答1個以上。完全一致で採点。
- `text`: choicesとcorrectは空配列、answerは空でない文字列。前後空白を除いて完全一致。
- 説明・単元・解説は空文字列可、カテゴリ・タグは空配列可。問題集は空でも作成可能。
- 問題文と選択肢の空欄、存在しない正答、ID・正答の重複を拒否。
- 未知のschemaVersionは推測して変換せず拒否。更新時は同じ問題集ID単位で置き換え、問題の部分マージはしません。

## 既存CSV（10列）

```text
type,question,choice1,choice2,choice3,choice4,choice5,choice6,answer,explanation
```

UTF-8（BOM可）。改行・カンマ・ダブルクォーテーションを含むセルは引用符で囲み、内部の引用符は2つにします。サンプルは `examples/science.csv`。

旧形式との互換のため、先頭見出しが `type` / `形式` / `問題形式` なら残りの列は位置で解釈します。解説のない9列、解説を複数列に分けた旧データも読みます。11列目以降は解説にカンマで結合し、警告を出します。

answerは `1` などの元の選択肢番号。複数は `1|3`。`single` でも複数の正答なら `multi` に変換して通知します。`1abc` のような数字以外の混在、存在しない番号、重複番号はエラーです。選択肢の途中の空欄は保持し、元の番号と解説の対応を維持します。

CSVにはカテゴリ・タグ・永続IDを保存しません。CSVを再度読み込むと新しい問題になります。これらを保ちたいときはJSONを使ってください。数式とみなされる先頭文字も、互換性のためCSVには元の内容で書き出します。表計算ソフトで開く際は信頼できるデータを利用してください。

## 旧manifestの移行

「読み込む → フォルダーを選ぶ」で `manifest.json` と対応するCSVを含むルートを選びます。文字列パス、`{title,path}`、配列、任意階層オブジェクトに対応します。

```json
{
  "分野A": {
    "カテゴリB": [{ "title": "単元C", "path": "data/c.csv" }]
  }
}
```

この場合カテゴリは `分野A / カテゴリB`、問題集名・単元は `単元C` になります。学校や教員に特化したキーは要求しません。相対パスだけが使え、上位ディレクトリ参照やネットワークURLは拒否します。フォルダー選択を提供しないブラウザではCSV単体を選び、分類をあとから設定できます。

全ファイルの読み込みと検査が成功した場合だけ、まとめて追加します。エラーがあると一部だけが保存されることはありません。

## HTMLの扱い

属性のない `br p strong b em i ul ol li` だけを文字装飾として表示します。その他のタグ・属性・スクリプト・リンク・画像はエスケープして文字表示します。データ自体は保持し、任意コードや外部リソースを実行・取得しません。従来の表・画像を含む問題は初版では同等表示になりません。
