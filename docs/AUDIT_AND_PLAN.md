# 既存コードの調査と移行計画

調査日：2026-10-21。対象は提供済みのソースZIP（更新日2026-10-03、バージョン表記2.2.1）。本番サーバーの現物・以降の差分は取得していません。そのため、このZIPを基準にした初版です。

## 流用と新規実装

| 機能 | 元サイト | 今回の対応 |
| --- | --- | --- |
| CSV | 10列、引用符・改行、単一・複数・記述 | 互換アダプター、厳密な正答検査を追加 |
| カテゴリ | 固定の上位2階層＋任意階層 | 上位階層の意味を撤廃、任意階層へ |
| 出題範囲 | 同一科目内の複数セット | 複数カテゴリ、タグ、問題数を追加 |
| シャッフル・採点 | あり | 元の選択肢IDを維持する方針を継承 |
| ナビ・回答確定 | 固定下部、前後、問題一覧 | 操作を継承、汎用UIで再実装 |
| 途中再開 | IDとCSVを照合して再読込 | 問題スナップショット付きに変更 |
| 履歴・誤答復習 | localStorage | IndexedDBに移行、新しい保存領域 |
| 作成・編集・複製 | なし | 新規実装 |
| 入出力 | メニューとCSVの読込 | CSV/JSON書出し、確認付き取込を追加 |
| リッチ表示 | HTMLと画像の表示・拡大 | 文字装飾のみ。画像管理は次期候補 |

アルゴリズムと操作設計を活用しつつ、学校用画面・保存キー・データ読み込み経路は持ち込みません。元ファイルをそのまま公開する方式ではありません。

## 除外・安全確認

ソースZIPにはCSV69個、PNG22個、JPG3個、データ埋め込み用JavaScript1個がありました。これらと私的メニュー、個別設置のアクセス制限ファイル、Macの付随ファイルは公開候補に含めません。コードの検査対象はアプリ・コア・ソース読込・CSS・HTMLです。依存パッケージと外部通信URLは、その範囲では見つかりませんでした。

公開候補は新しいディレクトリに作成し、非公開ZIPや問題集を一度もGitに追加しません。サンプルはこのプロジェクト向けに新規作成した6問です。コードには外部アセットを入れていません。チェック用スクリプトは既知の秘密情報パターンと除外ファイルを検査しますが、法的な権利確認や包括的なセキュリティ監査の代わりではありません。

元ソースにはLICENSEを確認できませんでした。利用者から自作サイトとして提供されたコードを基にしていますが、第三者由来のコードがある場合は所有者が出典と許諾を確認する必要があります。MITは公開案として同梱し、公開前に著作権者名・適用範囲を確認します。

## 開発順序

1. 非公開入力を分離し、再利用範囲・互換要件を調査する。
2. モデル、検証、CSV/JSON変換、セッションスナップショットを実装する。
3. 作成・分類・プレビュー画面と演習画面をつなぐ。
4. 入力エラー、採点、永続化、再開、レスポンシブ表示を検証する。
5. 元データ混入の点検、導入文書・テスト・CI・Issueテンプレートを整える。
6. 所有者が完成物・名前・ライセンス・公開範囲を確認する。
7. 承認後にGitHub公開・Pagesデプロイ・リリースを行う。

初版の次は、実機Safari/Androidの確認、画像添付、大量データ時の分割保存、UI部品の分離を優先します。クラウド同期や共同編集は利用者からの必要性が確認できてから検討します。

既存サイトの利用人数は所有者からの申告であり、OSS版の実績とは区別します。OSS版について利用者数・導入校数・成果などの実績を記載しません。
